# CatalogoRopa

Catálogo web de prendas y accesorios confeccionados de forma independiente.

## Estructura

- `FrontEnd/`: aplicación React con TypeScript y Vite.
- `BackEnd/`: espacio reservado para la futura API en ASP.NET Core.

## Desarrollo del frontend

```bash
cd FrontEnd
npm install
npm run dev
```

Las imágenes locales se colocan en `FrontEnd/src/assets/catalogo`, organizadas por categoría. El nombre de cada archivo representa el código del producto.
